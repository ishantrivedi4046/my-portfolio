# Security policy

Security owner: [@ishantrivedi4046](https://github.com/ishantrivedi4046).

Report vulnerabilities using the **Security → Advisories → Report a vulnerability**
button in this repository. Do not open a public issue containing credentials or an
unpatched vulnerability. Never include live credentials in a report.

Only the default branch is actively maintained. See
[security scanning operations](docs/security-scanning.md) for checks, exceptions,
dependency updates, and incident response.
